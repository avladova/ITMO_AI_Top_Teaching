# Конструктор компетенций КРМ v3.0

## Назначение

`index.html` — браузерный прототип конструктора компетенций по модели КРМ 3.0. Он предназначен для проектирования связки **компетенция → индикатор → уровень → дескриптор → результат обучения → оценочное средство → критерий** и последующей генерации проекта рабочей программы и КИМ.

## Тестовая дисциплина

Для демонстрации использована дисциплина репозитория: **«Вероятностно-статистические основы машинного обучения»**, направление 09.03.01, 4 ЗЕТ / 144 академических часа.

## Возможности прототипа

- выбор целевой роли выпускника;
- выбор компетенций КРМ и фильтрация по блокам;
- выбор индикаторов;
- отображение дескриптора;
- выбор КИМ и проверяемых индикаторов;
- расчёт глубины покрытия `q`;
- формирование проекта рабочей программы;
- формирование проекта КИМ;
- формирование матрицы соответствий;
- экспорт конфигурации в JSON;
- печать результата через браузер.

## Математическая логика

Прототип использует представление КРМ как ориентированного мультиграфа. Для проверки согласованности используются идеи покрытия `P`, глубины покрытия `q` и локальной несогласованности `δ`. Формируемые документы являются проектом и требуют экспертной верификации содержания, уровней, критериев и результатов обучения.

## Запуск

Открыть `index.html` непосредственно в браузере. Сервер не требуется. Конструктор не содержит механизма записи в GitHub и не выполняет push/commit самостоятельно.

## Ветка разработки

Рабочая версия конструктора находится в ветке `feature/krm-competency-constructor`. Файлы конструктора намеренно не должны добавляться в основную ветку `main`.

## Ограничения текущего прототипа

Справочник компетенций и индикаторов встроен в HTML как демонстрационный набор. Для промышленного варианта его следует вынести в отдельный JSON/CSV/Excel и подключить полный справочник КРМ 3.0, а также расширить редакторы дескрипторов, критериев, тем, оценочных заданий и методических ресурсов.
